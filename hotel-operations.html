Hotel operations

Practical project for the DataCamp SQL Associate certificate, finished 17 October 2026. LuxurStay’s room-service ratings had fallen below the 4.5 target. I cleaned the branch table, then measured response time and ratings by hotel and service. This is querying on a provided dataset, not production database administration.

Open the SQL Read the notes

Tables

Only requests that received a feedback rating are in the data. A request belongs to one service and one branch.

service

  • id
  • description

request

  • id
  • service_id
  • branch_id
  • time_taken
  • request_time
  • rating

branch

  • id
  • location
  • total_rooms
  • staff_count
  • opening_date
  • target_guests

What the queries do

  • Replace invalid branch locations with Unknown, room counts outside 1–400 with 100, missing staff with 1.5 times the cleaned room count, bad opening years with 2023, and guest-type typos such as B. and Busniess with Business or Leisure.
  • Average and maximum minutes to answer a request, for each branch and service, rounded to two decimals.
  • List Meal and Laundry requests in EMEA and LATAM, using the original branch table.
  • Keep branch and service pairs whose average rating, rounded to two decimals, is under 4.5.

Clean the branch table

SELECT
    id,
    CASE
        WHEN location IN ('EMEA', 'NA', 'LATAM', 'APAC') THEN location
        ELSE 'Unknown'
    END AS location,
    CASE
        WHEN total_rooms BETWEEN 1 AND 400 THEN total_rooms
        ELSE 100
    END AS total_rooms,
    COALESCE(
        staff_count,
        1.5 * CASE
            WHEN total_rooms BETWEEN 1 AND 400 THEN total_rooms
            ELSE 100
        END
    ) AS staff_count,
    CASE
        WHEN opening_date BETWEEN '2000' AND '2023' THEN opening_date
        ELSE '2023'
    END AS opening_date,
    CASE
        WHEN TRIM(target_guests) ILIKE 'B%' THEN 'Business'
        ELSE 'Leisure'
    END AS target_guests
FROM branch;

Time, target hotels, and low ratings

SELECT
    service_id,
    branch_id,
    ROUND(AVG(time_taken), 2) AS avg_time_taken,
    ROUND(MAX(time_taken), 2) AS max_time_taken
FROM request
GROUP BY service_id, branch_id;
SELECT
    s.description,
    b.id AS branch_id,
    b.location,
    r.id AS request_id,
    r.rating
FROM request AS r
JOIN branch AS b ON r.branch_id = b.id
JOIN service AS s ON r.service_id = s.id
WHERE s.description IN ('Meal', 'Laundry')
  AND b.location IN ('EMEA', 'LATAM');
SELECT
    service_id,
    branch_id,
    ROUND(AVG(rating), 2) AS avg_rating
FROM request
GROUP BY service_id, branch_id
HAVING ROUND(AVG(rating), 2) < 4.5;
