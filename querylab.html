QueryLab

A question box for a CSV or SQLite file on this PC. You ask in plain language. QueryLab writes one SELECT, runs it, and shows the rows. Ollama on this PC writes the SQL. The working copy sits in the querylab data folder.

Read the setup Launcher

How to run it

  • Double-click querylab/start_querylab.cmd. The browser opens at http://127.0.0.1:8765/.
  • Load the sample help-desk tables, or upload your own CSV or SQLite file. Several CSVs become several tables.
  • Ask a question, read the SQL, edit it if you want, and press Run SQL.
  • Plain-language questions use a model already installed in Ollama. The app picks llama3 when it is installed. Run SQL works with Ollama closed.
  • Write the finding yourself. The checklist asks for the number, the group, and which rows were included. Save keeps the draft in the data folder.

Write-up practice

The page fills the question and the SQL. The finding, the reading of the rows, the caveat, and the one-liner stay blank until you write them. Download saves a markdown file. The data folder is on this PC and is not part of the published source.

What you can load

  • CSV or TSV. Each file is one table. Excel needs Save As, CSV, first.
  • A SQLite file (.db, .sqlite, .sqlite3). QueryLab copies it and queries the copy.
  • The sample: fictional campus tickets, plus the team for each technician.

Each question runs as one read-only SELECT. The result shows at most 500 rows.

Sample checks

  • How many open tickets are there for each priority?
  • Which team has the most open tickets?
  • What is the average minutes to resolve a closed ticket, by site?
