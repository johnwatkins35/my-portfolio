# Hotel operations

Practical project for the DataCamp SQL Associate certificate, finished 17 October 2026.

LuxurStay is a fictional hotel chain. Management said room service was slow and customer satisfaction had fallen below the 4.5 target. The tables are `branch`, `request`, and `service`. Only rows with a feedback rating are included.

The SQL is in `queries.sql`. It is querying and cleaning on a provided PostgreSQL dataset, not production database administration.

The certificate also included a timed exam. The domains were data management and exploratory analysis.
