# Harborline dashboard

Practice lab for an interactive Excel dashboard. Harborline is fictional.

The workbook is won revenue for January through October, 2025 and 2026. Open `harborline-dashboard.xlsx` in the Excel desktop app. Dashboard is the click-through. Walkthrough is the ten steps.

`build_dashboard.py` rebuilds the workbook with Excel installed. It writes the Bookings table, the PivotTables, the slicers, and the charts.
