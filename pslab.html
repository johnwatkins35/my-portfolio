PowerShell practice lab

PSLab

A throwaway PowerShell 7 shell in Docker. The container is deleted when you exit. The only folder on the PC it can change is work. Windows services, local users, and Active Directory stay on a Windows VM you can snapshot. This is a practice box, not production automation.

Read the setup Command cheatsheet

What is in the lab

  • Launcher that starts Docker if it is down, then opens the sandbox
  • Caps of 2 CPUs and 1 GB RAM, with no admin rights on the host
  • Sample CSV files for services, users, and groups, plus short scripts
  • Reset that copies the practice folder aside, then restores the samples
  • Active Directory notes for a lab.local domain controller on a VM, not on this PC
