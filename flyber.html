Main project

Flyber MVP launch analysis

Course project for a fictional eVTOL air-taxi launch in Manhattan. I loaded NYC taxi rides and a 500-person survey into local Docker PostgreSQL, wrote SQL, charted results in Python, and published the workbook on Tableau Public. This is querying and analysis, not production database administration.

Open Tableau workbook Sample SQL

What is in the lab

  • Local PostgreSQL on Docker (port 5433) with taxi rides and survey tables
  • SQL for volume, time-of-day, passenger counts, willingness to pay, and zip-level interest
  • Python (pandas, matplotlib) charts for the midterm deck
  • Tableau Public sheets for taxi use, rideshare, income, seasonality, and pickup/drop-off work
