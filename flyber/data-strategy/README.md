# Flyber scalable data strategy

Course project for a fictional flying-taxi company. The event pipelines cannot keep up with the live app.

This folder holds the charts and the Tableau Public workbook. The full event-log extract is not included.

- `index.html` is the write-up.
- `flyber-total-event-growth.png`, `flyber-all-event-types.png`, and `flyber-all-events-log-scale.png` are the growth charts.
- `flyber-open-events.png` and `flyber-begin-ride.png` are the two single-type charts.
- `Flyber-Event-Growth.twbx` is the Tableau workbook (Open, Begin Ride, all event types, log scale, and one dashboard).
