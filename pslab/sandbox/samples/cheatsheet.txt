Files here
  services.csv     sample list of services
  tables.txt       practice for building a table

See files
  Get-ChildItem

Read the sample
  Import-Csv ./services.csv

Only the running ones
  Import-Csv ./services.csv | Where-Object Status -eq Running

Names only
  Import-Csv ./services.csv | Where-Object Status -eq Running | Select-Object -ExpandProperty Name

How many are running
  Import-Csv ./services.csv | Where-Object Status -eq Running | Measure-Object

Save a result into a new file
  Import-Csv ./services.csv | Where-Object Status -eq Running | Export-Csv ./running.csv -NoTypeInformation
