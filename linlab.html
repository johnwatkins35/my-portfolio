Linux practice lab

LinLab

The same idea as PSLab, for Linux. It opens an Ubuntu shell in Docker. The container is deleted when you exit. The only folder on the PC it can change is work. Packages installed with apt disappear on exit. Files in the practice folder stay. This is a practice box, not a production server.

Read the setup Command cheatsheet

What is in the lab

  • Launcher that starts Docker if it is down, builds the image once, then opens the sandbox
  • Caps of 2 CPUs and 1 GB RAM, with no admin rights on the host
  • Sample files for services, accounts, a log, and a short shell script
  • Reset that copies the practice folder aside, then restores the samples
  • Everyday tools already in the image: bash, grep, awk, nano, curl, and jq
